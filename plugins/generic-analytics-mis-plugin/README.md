# generic-analytics-mis-plugin

Version 0.1.0. Generated by MIS Plugin Forge for the **Generic Analytics Pack** industry pack.

## Setup

Install this plugin from its GitHub marketplace. Claude Desktop/Code start the hosted MCP from `.mcp.json` automatically — no local Python and no `claude_desktop_config.json`.

## Available KPIs

- `average_measure` - Average of Primary Measure
- `sum_measure` - Sum of Primary Measure
- `total_records` - Total Records
- `trend_by_month` - Trend by Month
